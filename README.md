# Mabina Seafood website

A multilingual (English, French, Arabic) single page restaurant website for a seafood restaurant in Al Hoceima, Morocco. Built with React and Vite.

## Run it
```bash
npm install --legacy-peer-deps
npm run dev
npm run build
```
Note: `--legacy-peer-deps` is needed because react-day-picker 8 does not list date-fns 4 as a peer. `npm run build` runs image validation and lint first (`prebuild`).
