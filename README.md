# Mabina Seafood website

A multilingual (English, French, Arabic) single page restaurant website for a seafood restaurant in Al Hoceima, Morocco. Built with React and Vite.

## Run it
```bash
npm install
npm run dev
npm run build
```
Note: `npm run build` runs image validation and lint first (`prebuild`).

## Notes
- Restaurant name, photos, menu and contact details are the restaurant's content, not open source assets.
- No license has been chosen, so all rights are reserved.
